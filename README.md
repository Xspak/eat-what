- # 今天吃什么（转盘/翻牌小工具）

  这是一个基于 Python Flask 的小工具，支持“转盘”和“翻牌”两种模式，可以手动添加选项，也可以基于高德地图 API 自动拉取附近的餐厅。

  ## 常规启动流程

  1. 安装依赖：
     pip install -r requirements.txt

  2. 配置高德 Key（必须，否则无法拉取餐厅）：
     - 参考下方【高德 API 申请流程】。
     - 打开 app.py，找到第 9 行，将 "你的高德Web服务Key" 替换为你自己的 Key：
       AMAP_KEY = os.environ.get("AMAP_KEY", "你的高德Web服务Key")

  3. 运行项目：
     python app.py
     
  4. 启动后，在浏览器访问 http://127.0.0.1:5000 即可开始使用。
     （注：此模式下“自动定位”功能受浏览器安全限制无法使用，请使用页面上的“手动坐标定位”功能，去高德坐标拾取器复制经纬度填入即可。）

  ---

  ## 高德 API 申请流程

  1. 访问 高德开放平台 (https://lbs.amap.com/)，注册并登录账号。
  2. 进入“控制台” -> “应用管理” -> “我的应用”，点击“创建新应用”。
     - 应用名称随意填（如：今天吃什么），应用类型选“出行”或“其他”。
  3. 创建成功后，点击“添加 Key”。
     - Key 名称：随意填。
     - 服务平台：⚠️ 必须选择「Web服务」（注意：不是 Web端(JS API)）。
     - 勾选“阅读并同意”，点击提交。
  4. 复制生成的 Key（32位字符），填入 app.py 中即可。

  ---

  ## 常见问题排查

  ### 1. 报错 INVALID_USER_KEY
  - 检查 app.py 里的 Key 是否前后有空格。
  - 检查高德控制台里的 Key 类型是否为「Web服务」，如果是“Web端(JS API)”则会报错。

  ### 2. 拉取不到附近的餐厅
  - 检查手动输入的坐标格式是否正确（必须是 经度,纬度，用英文逗号隔开）。
  - 尝试在页面上多选几个“餐馆类型”，或者把搜索半径调大。

  ---

  ## 可选进阶配置：开启 HTTPS（解锁自动定位）

  浏览器（特别是手机端）规定，只有在 HTTPS 环境下才允许调用系统的定位权限。如果你希望使用页面上的“自动定位”功能，需要开启 HTTPS。

  1. 生成证书：
     在终端运行以下脚本，它会自动在当前目录生成 10 年有效期的 cert.pem 和 key.pem：
     python gen_cert.py

  2. 运行项目：
     python app.py
     此时 app.py 会自动检测到证书，并以 HTTPS 模式启动。

  3. 访问项目：
     在浏览器访问 https://127.0.0.1:5000。
     - 因为是自签证书，浏览器首次访问时会提示“连接不安全”，点击“高级” -> “继续前往”即可。
     - 如果是给局域网内其他同事使用，需要输入 https://电脑局域网IP:5000。
     - 如果手机无法访问或提示安全拦截，建议直接删掉 cert.pem 和 key.pem 文件，退回到纯 HTTP 模式，仅使用手动坐标。
